# Q1154: exponential upper bound for a winning family (known-derived; unnumbered)

The [published Conjecture 5, §3, printed and PDF p. 11](https://dmtcs.episciences.org/en/articles/19063/download#page=11) asks if f(n) is bounded above by c^n for some fixed c>1 at all sufficiently large n. Here f(n) is the smallest size of a family F giving the first player a forced win when both players play for F. This follows by adjoining one common cell to the published second-player Maker–Breaker block construction of Theorem 4; it is not counted as a new independent solve.

For n≥6 select the forced cell (1,1); put N=n−1=5k+r for k≥1 and 0≤r≤4. On the board remaining after deleting row and column 1, use k−1 disjoint diagonal 5×5 blocks and a final diagonal (5+r)×(5+r) block, partitioning the remaining rows and columns. Take all transversals consisting of (1,1) and one transversal in every block. X opens on (1,1), so O can never complete any winning set. The published Claim in the proof of Theorem 4 says Maker, playing second, can form a transversal on each full block of size at least 5 against arbitrary Breaker moves. Apply these local strategies simultaneously.

In detail, X answers an O move in an unfinished block according to that block's strategy. If O plays outside the unfinished blocks, or on a cell already recorded as a virtual Breaker move, instead choose an unfinished block and simulate any legal Breaker move there. Every actual O mark in an unfinished block is thus recorded as a virtual Breaker mark. Every free simulated Maker response is actually free in that block; if a virtual Breaker move would exhaust the block, its second-player strategy guarantees Maker already has a transversal. Every round advances play in some unfinished block, and thus all blocks finish in finitely many rounds. An unfinished block with a virtual legal response also has a physically unoccupied cell, so the actual game cannot end in a draw beforehand.

The number of winning sets is (5!)^(k−1)(5+r)!≤(6·7·8·9)(5!)^k≤3024·3^(n−1) since 5!<3^5. Thus c=4 works for all sufficiently large n. More precisely, limsup f(n)^(1/n)≤120^(1/5). The common cell reduces the exact strong-game question to the paper's weak-game block strategy; simply using the weak winning family without it would not rule out an O win.
