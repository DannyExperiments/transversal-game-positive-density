# Four-by-four board

Pair rows (1,2) and (3,4) and the same column pairs. In each of the four resulting blocks, both diagonals give disjoint cell pairs. The transversal with columns (2,1,4,3) uses the antidiagonal in each of two blocks. If X first claims (1,2), O claims its mate (2,1), blocking that transversal immediately. The same response works on the first claimed cell of any prescribed pair. A particular pairing response does not need to know which transversal X is aiming for.

In this board there are eight possible prescribed pairs. A uniform permutation contains any specified pair with probability 1/12. Compatible pairs of pairs come in eight possibilities, each fixing its full transversal. The inclusion–exclusion count is 24 × (8/12−8/24)=8 transversals, one third of the total. All eight contain two complete pairs. The remaining 16 contain zero.

The rotating board shows the example above. The explorer lets readers select all 24 transversals and see a blocking reply whenever the example family contains the selected transversal.
