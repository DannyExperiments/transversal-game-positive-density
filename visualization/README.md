# Offline pairing explorer

Extract both files together and open index.html. Select one of the 24 transversals by its columns, listed from top row to bottom row. The 3D board highlights its cells and joins each complete prescribed pair. Enable the example response to see the second player take the mate of the first player’s selected cell.

Only eight transversals belong to the worked family on the four-by-four board. The paper proves the positive limiting fraction as the board grows.
